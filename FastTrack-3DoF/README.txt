# Planar 3-DOF Robot Target Tracking
基于雅可比矩阵与代价函数的平面三连杆机器人多目标点访问与运动控制

## 项目简介
针对平面三连杆机器人多目标点访问问题，根据当前关节状态和目标点位置，利用正运动学计算末端位置，通过雅可比矩阵伪逆求解关节速度，并结合末端距离与关节速度构建代价函数，实现目标点选择与运动控制。

## 主要方法
- 正运动学
- 雅可比矩阵
- 伪逆求解
- 末端位置误差计算
- 目标点筛选与选择
- 关节速度控制

## 文件说明
- `MyAnswer.m`：机器人目标点选择与关节速度控制主程序
- `Jacobian.m`：平面三连杆机器人的雅可比矩阵计算
